## Theory
Tree contains many nodes which can point(edges) to others
It comes in different structure
There are parent and child node - relative relationships
A root is a node that dont have any parents
A node which dont have any child its the leaf node
In Binary tree we typically we have one root and many leafs
**Binary Tree - is a tree where every node have atmost 2 children**
### Binary tree - should satisfy these 3 conditions
1. so it can have 0 or 1 or 2 children(atmost 2) for a node if its a binary node
2. it will have only one root - top most node
3. it has exactly 1 path between the root and any node - one possible path

Fun fact - empty tree is also a tree

We represent the left and right node with node.left and node.right
